# BlockCraft — Mini mundo en HTML

Un mini sandbox 2D inspirado en Minecraft, hecho con HTML, CSS y JavaScript puro. No necesita instalación, servidor ni librerías externas.

## Cómo jugar
- Abre `index.html` en un navegador.
- **WASD o flechas:** moverte.
- **W / ↑ / espacio:** saltar.
- **Clic izquierdo:** minar bloques.
- **Clic derecho:** colocar el bloque seleccionado.
- **1–6:** cambiar de bloque.
- **R:** generar otro mundo.
- En móvil aparecen controles táctiles.

## Publicarlo con GitHub Pages
1. Abre **Settings → Pages** en este repositorio.
2. En **Build and deployment**, elige **Deploy from a branch**.
3. Selecciona la rama `main` y la carpeta `/ (root)`, y guarda.
4. Espera a que termine el despliegue. La web debería quedar en `https://diegox222013.github.io/blockcraft-html/`.

Este proyecto es un juego original inspirado en la mecánica de construir y minar bloques; no contiene recursos oficiales de Minecraft.
